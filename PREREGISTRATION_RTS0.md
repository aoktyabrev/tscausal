Запечатано до первого прогона RTS и **до чтения отчёта литчека R.0** (субагент запущен, отчёт не прочитан).
Код RTS не написан. Числа Renou и формулировки HW в этот файл не вписаны — они будут взяты из цитат (SOURCES.md).

## Определения (фиксируются здесь)
- **Сценарий:** бинокальный сценарий Renou et al. (стороны A, B, C; B выполняет совместное измерение на двух
  входах B_I1 ⊗ B_I2). Перевод в TS без селекции по образцу D8: источник ↦ канал от выхода стороны к входу B
  при максимально смешанном глобальном прошлом; «настройка» стороны ↦ её **исход**, «результат» ↦ её **доход**
  (как в D8); у B — настройки нет, 4 исхода. Кардинальности исходов и доходов — как у настроек и результатов
  Renou; двойная причинность — MH-1 с множителями N (MH24 ур. (2)).
- **Класс:** ISO₃ (D10) для сторон A, B, C с составным входом B. Линейные условия — тем же кодом нуль-пространства,
  что в T3.0 (калибровка: N = 2 → 19). Вещественный класс — W вещественная симметричная; операции вещественные
  симметричные.
- **Операциональная независимость каналов (процессный уровень).** Основное определение — определение HW
  (цитата из 2603.19208), перенесённое на процессы. Запасное (если перенос неоднозначен): для любых локальных
  TS-операций A и C и любых **произведённых** операций B вида M_{B1} ⊗ M_{B2} (отдельные доход и исход на каждом
  порту) совместное распределение факторизуется: p(a, b₁, b₂, c) = p(a, b₁) · p(b₂, c).
- **Верхняя оценка (R.3):** SDP-релаксация по W (при фиксированных операциях — точно) и see-saw; расхождение
  с комплексным значением засчитывается только при верхней оценке, отделённой от него, и пересчёте в mpmath.

## Прогнозы

**Архитектор:**
- R.0: вещественная КМ в TS-формализмах без селекции в литературе не рассматривалась — средняя;
- R.2: 4-частичные члены с J-множителем на каждом канале допустимы в ISO — средняя-высокая;
- R.3: вещественный ISO с операциональной независимостью достигает комплексного T, то есть HW переносится — ~55%.

**Исполнитель:**

| пункт | прогноз | уверенность |
|---|---|---|
| R.0 | вещественную КМ в процесс-матрицах / TS-формализмах / при максимально смешанном глобальном прошлом никто не рассматривал | 0.7 |
| R.1 | комплексный ISO-процесс (тождественные каналы, D8) воспроизводит комплексное T Renou точно | 0.85 |
| R.1 | вещественные процессы-произведения дают не больше вещественной границы Renou | 0.9 |
| R.2 | члены вида J^{A_O} J^{B_I1} J^{C_O} J^{B_I2} (и с J на «мнимых» кубитах) допустимы в ISO₃ — следует из правила «∃ только вход ∧ ∃ только выход» | 0.95 |
| R.2 | RQT-модель HW переводится в вещественный ISO-процесс (положительная, в классе) | 0.65 |
| R.2 | J⊗J-члены удовлетворяют операциональной независимости | 0.7 |
| R.3 | вещественный ISO с операциональной независимостью достигает комплексного T (HW переносится) | 0.65 |
| итог | исход «HW переносится, закрыто отрицательно» | 0.6 |

Рассуждение: связь двух каналов через «мнимые» кубиты — член, где у B «только вход», у A и C «только выход»;
правило ISO его допускает. Максимально смешанное прошлое не мешает: корреляция мнимых кубитов переносится
процессом (каналом), а не состоянием прошлого. Главный риск для переноса — положительность и требование,
чтобы TS-операции оставались TS после вещественного вложения.
