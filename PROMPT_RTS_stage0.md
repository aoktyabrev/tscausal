# PROMPT RTS stage 0 — закрывает ли временная симметрия лазейку вещественной КМ

Новая ветка, продолжение TSCAUSAL (леммы D6, D8) и [[quantum-reconstruction]] (спор
Renou против Hoffreumon–Woods). Правила прежние: Правило 0, предрегистрация отдельным
коммитом до первого прогона, `RESULTS.md` порождается скриптом, каждый оценщик
калибруется на случае, где он может провалиться.

## Вопрос

Hoffreumon–Woods (arXiv:2603.19208, март 2026): при операциональной независимости
источников вещественная КМ (RQT) воспроизводит любые сетевые корреляции (Теорема 1) и
любые конечные последовательные протоколы с каналами и измерениями (Теорема 2).
Механизм: состояния источников в RQT-модели не являются произведениями, но локально
неотличимы от них; канонический пример ¼(I⊗I − αJ⊗J) с антисимметричной J (Caves et al.).

Во временно-симметричном режиме без селекции (Mrini–Hardy, класс ISO) глобальное
прошлое максимально смешано, а допустимые члены процесс-матрицы ограничены линейными
условиями (для двух сторон: только 1, A_O B_I, A_I B_O — лемма D6).

**Помещается ли скрытая корреляция, нужная RQT-модели, в вещественный класс ISO?**
- Нет → при фундаментальной временной симметрии RQT опровержима там, где Теорема 2 HW
  говорит, что без неё неопровержима. i необходим из-за симметрии времени.
- Да → Теорема HW переносится на TS-режим; это тоже результат (закрывает вопрос).

## R.0 — литчек (до расчётов)

3. Hoffreumon–Woods 2025 (RNQT), Barrios Hita et al. arXiv:2503.17307, Feng–Ren–Vedral
   arXiv:2504.07808, Weilenmann–Gisin–Sekatski arXiv:2502.20102, «Partial independence
   suffices…» (PRL 2025).
4. Поиск: рассматривал ли кто-то вещественную КМ в процесс-матрицах, при неопределённом
   причинном порядке, во временно-симметричных формализмах (Oreshkov–Cerf, Mrini–Hardy)
   или в режиме с максимально смешанным глобальным прошлым. Если да — это первая строка
   отчёта.

## R.1 — перевод бинокального сценария в TS без селекции (ворота)

По образцу D8: источники → тождественные каналы из максимально смешанного прошлого,
роли настроек и исходов как в D8. Построить комплексный ISO-процесс для трёх сторон
(A, B, C; у B два входа), воспроизводящий корреляции Renou.

Калибровки:
- комплексный ISO-процесс даёт комплексное значение T из статьи Renou;
- вещественные процессы-произведения (W = W₁ ⊗ W₂, оба вещественные) дают не больше
  вещественной границы Renou (see-saw, не менее 50 стартов) — воспроизведение их
  результата в нашем языке;
- принадлежность ISO проверена двумя независимыми путями, как в T3.0.

## R.2 — структура членов в вещественном базисе (главный пункт)

1. Нуль-пространство линейных условий ISO для этой конфигурации в базисе, содержащем
   антисимметричные генераторы (J-типа). Какие типы членов с J-множителями допустимы?
   Отдельно: допустимы ли члены, связывающие два канала (4-частичные, по одному
   J-множителю на каждый канал), и в каком виде.
2. Перевести RQT-модель HW для бинокального сценария в процессный язык. Лежит ли она в
   вещественном ISO? Если нет — какой член её выводит, и можно ли его заменить
   допустимым без потери операциональной независимости.
3. Определить операциональную независимость на уровне процессов: отсутствие наблюдаемых
   корреляций между каналами при любых локальных TS-операциях. Проверить, что
   ¼(I⊗I − αJ⊗J)-подобные члены, если они допустимы, ей удовлетворяют.

## R.3 — прямой тест

Максимум T по вещественным ISO-процессам с операциональной независимостью каналов
(see-saw + SDP-релаксация сверху, где возможно). Сравнить с комплексным значением.
- совпадает → HW переносится на TS;
- строго меньше, с верхней оценкой, отделённой от комплексного значения → кандидат в
  результат «временная симметрия делает RQT опровержимой»; дальше — доказательство.

Любое заявленное расхождение подтверждается верхней оценкой (не только see-saw) и
пересчётом в точной или расширенной точности.

## Предрегистрация

Свои предсказания по R.0–R.3 с уверенностью. Прогнозы архитектора отдельными строками:
- R.0: вещественная КМ в TS-формализмах без селекции в литературе не рассматривалась
  (уверенность средняя);
- R.2: 4-частичные члены с J-множителем на каждом канале допустимы в ISO (уверенность
  средняя-высокая);
- R.3: вещественный ISO с операциональной независимостью достигает комплексного T,
  то есть HW переносится (уверенность ~55%).

## Исходы, зафиксированные заранее

- HW переносится → закрыто отрицательно: временная симметрия не спасает тест Renou;
  фиксируется явная RQT-конструкция в ISO;
- не переносится с отделённой верхней оценкой → главный кандидат ветки; литчек новизны
  и аналитическое доказательство до любых заявлений;
- R.1 не пройдена → сначала перевод сценария, выводы не делаются.
