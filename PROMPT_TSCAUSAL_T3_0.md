# PROMPT TSCAUSAL stage T3.0 — три зеркала

Двусторонняя ветка закрыта: лемма D6 (без селекции любой процесс Mrini–Hardy — смесь
односторонних каналов) и лемма D8 (сведение к белловскому сценарию). Новый вопрос:
**обобщается ли D6 на три стороны**, или временная симметрия без селекции допускает
неопределённость порядка, начиная с трёх сторон.

Правила репозитория прежние: Правило 0, предрегистрация отдельным коммитом до первого
прогона, `RESULTS.md` порождается скриптом, каждый оценщик калибруется на случае, где он
может провалиться, нарушения засчитываются только после пересчёта в mpmath.

## Контекст из литчека архитектора (проверить по первоисточникам, с цитатами)

- Baumeler, Costa, Ralph, Wolf, Zych, «Reversible time travel with freedom of choice»,
  CQG 36, 224002 (2019), arXiv:1703.00779: любая логически согласованная детерминированная
  классическая динамика реализуется обратимыми взаимодействиями; три стороны могут быть
  взаимно в прошлом и будущем.
- Процесс Лугано (Araújo–Feix, Baumeler–Wolf, NJP 18, 013036, 2016) нарушает причинные
  неравенства; его отображение выходов во входы необратимо (000 и 111 оба дают 000).
- arXiv:2201.11832: реализация всех унитарных расширений трёхсторонних процессов на
  временно-делокализованных подсистемах, с глобальными прошлым и будущим.
- Tobar–Costa, CQG 37, 205011 (2020), arXiv:2001.02511 — обратимая динамика с CTC.

Главное, что надо установить из источников: **в каком состоянии приготовлено глобальное
прошлое P в обратимом расширении Лугано** — фиксированное (в языке Mrini–Hardy это
предселекция) или произвольное.

## T.0 — структура членов (аналитика + нуль-пространство, ворота)

Для трёх сторон A, B, C (кубиты) выписать с цитатами общий вид TS-процесс-матрицы
Mrini–Hardy для N сторон (если статья даёт только двусторонний случай — достроить и
пометить как вывод). В режиме без селекции (u, v маргинализованы) найти нуль-пространство
линейных условий в базисе Паули:
- размерность, перечень допустимых типов членов;
- есть ли члены, чьи носители пересекаются (например, A_O B_I и A_O C_I);
- есть ли трёхчастичные члены (вход одной стороны от выходов двух других).

Калибровка: тот же код на двух сторонах воспроизводит 19 базисных элементов (d = 2) из
Stage C.

Развилка:
- **все допустимые члены попарно коммутируют** → попытаться доказать обобщение D6
  (смесь односторонних каналов / причинно разделимых процессов) для трёх сторон, а затем
  для N; это закрывает направление положительным структурным результатом;
- **есть некоммутирующие или трёхчастичные члены** → доказательство D6 не переносится,
  идём в T.1.

## T.1 — Лугано в режиме без селекции

1. Построить обратимое расширение процесса Лугано по источникам: биекцию
   (P, a_O, b_O, c_O) → (F, a_I, b_I, c_I).
2. Проверить три режима: (а) P фиксировано, как в источнике — калибровка, должно
   воспроизводиться нарушение причинного неравенства из Baumeler–Wolf с их числом;
   (б) P равномерно случайно, F отброшено — это режим без селекции Mrini–Hardy;
   (в) перебор всех обратимых расширений минимальной размерности P, если их конечно много.
3. Для (б) и (в): принадлежность классу без селекции (проверка линейных условий) и
   значение причинного неравенства (трёхстороннее, из Baumeler–Wolf или Abbott et al.,
   Quantum 1, 39, 2017, с цитатой формы и границы).

Ключевой вопрос: переживает ли нарушение усреднение по случайному P.

## T.2 — поиск за пределами Лугано (только если T.0 открыло дверь)

- Классические детерминированные трёхсторонние процессы, удовлетворяющие условиям без
  селекции (для бинарных переменных — перебор; ожидается, что это биекции с
  дополнительными ограничениями).
- Квантовые: see-saw по W̄ в классе без селекции на известных трёхсторонних причинных
  неравенствах, кубиты. Калибровка see-saw — известное значение нарушения для
  прямого формализма из литературы, с цитатой.

## Предрегистрация

Свои предсказания по T.0–T.2 с уверенностью. Прогнозы архитектора отдельными строками:
- T.0: появятся члены с пересекающимися носителями, доказательство D6 не переносится
  буквально (уверенность средняя-высокая);
- T.1: в источниках глобальное прошлое P фиксировано, то есть это предселекция
  (уверенность средняя);
- T.1(б): при случайном P нарушение Лугано исчезает (уверенность средняя —
  главный вопрос);
- T.2: хотя бы один процесс без селекции нарушает трёхстороннее причинное неравенство
  (уверенность низкая).

## Исходы, зафиксированные заранее

- D6 обобщается на три стороны (аналитически) → «временная симметрия без селекции
  запрещает неопределённость порядка при любом числе сторон» (если N-сторонний
  случай тоже проходит); сильный структурный результат;
- найден процесс без селекции с нарушением → «запрет только для двух сторон»;
  явный свидетель, пересчёт в mpmath, сравнение с Лугано;
- ни доказательства, ни свидетеля → зафиксировать, что именно блокирует каждое, числами.

## Отчёт

Числа, явные процессы, доказательства или их отсутствие, пройденные и проваленные
антивакуумные тесты, отклонения от промпта с обоснованием.
