Итог T3.0 принят. Правила репозитория прежние: Правило 0, предрегистрация отдельным
коммитом до первого прогона, `RESULTS.md` порождается скриптом, калибровка каждого
оценщика на случае, где он может провалиться.

## Что архитектор проверил независимо (внести в RESULTS.md как внешнюю сверку)

Отдельный скрипт с нуля, без кода репозитория:
- детерминированных стратегий с динамическим порядком (первая сторона по своему входу,
  выбор второй и функции остальных зависят от входа первой): **138 304 различных** —
  совпадает с T3.0;
- причинная граница G*: **3/4** — совпадает;
- Лугано выигрывает G* с вероятностью 1, его зеркало (инверсия всех входов и выходов)
  **тоже 1 по отдельности**.

Следствие для интерпретации: выигрыш W* = ½(Лугано + зеркало) на G* тривиально следует
из выигрыша каждой компоненты. Содержательная часть результата не в значении игры, а в
том, что **симметризованная смесь лежит в ISO₃** (без пред- и постселекции), тогда как
каждая компонента требует предселекции. Все дальнейшие формулировки строить вокруг
этого.

## T3.1.a — литчек новизны (главный пункт, до расчётов)

Проверить по полному тексту, с цитатами в `SOURCES.md`:
1. Понятие **«процессы без глобального прошлого»**: Steffinlongo–Dourdent,
   arXiv:2502.15579 (Phys. Rev. Research, 2026) — они вводят класс «superposition of
   classical communications», полученный из классических процессов без глобального
   прошлого. Выяснить определение и совпадает ли оно с нашим ISO₃ (или с его частью).
2. Baumeler, Costa, Ralph, Wolf, Zych, arXiv:1703.00779 — обратимые расширения: есть ли
   там расширения с равномерно случайным глобальным прошлым, и рассматривается ли смесь
   процесса с его образом под инверсией.
3. Tobar–Costa, arXiv:2001.02511; Araújo, Feix, Navascués, Brukner, «A purification
   postulate…», Quantum 1, 10 (2017); Kunjwal–Baumeler, PRL 131, 120201 (2023).
4. **«Reversed Lugano process»** — Phys. Rev. Research 4, 013180 (2022) и их ссылка [11]
   (causal reference frames). Установить, что именно там называется обращённым Лугано
   (обмен входов и выходов или что-то иное) и как это соотносится с нашим зеркалом
   (инверсия значений) и с ISO₃.

Если хоть в одной работе уже показано, что Лугано (или иной некаузальный классический
процесс) реализуется без фиксированного глобального прошлого и без глобального будущего
с нарушением причинного неравенства, — записать это первой строкой отчёта. Тогда наш
вклад сужается до: перевод в формализм Mrini–Hardy плюс контраст «две стороны — запрет
(D6), три — нет».

## T3.1.b — объяснение разницы с игрой BW16

Посчитать значения BW16 на Лугано и на его зеркале по отдельности. Ожидание архитектора:
1 и 0, откуда ½ для смеси. Сформулировать общий принцип: смесь с зеркалом сохраняет
нарушение только тех неравенств, которые (почти) инвариантны относительно зеркала.
Проверить: G* инвариантна относительно инверсии? Какие ещё известные трёхсторонние
причинные неравенства инвариантны, и какие значения на них даёт W*?

## T3.1.c — какие «зеркала» работают

Группа локальных инволюций значений для трёх бинарных сторон: инверсия каждого бита у
каждой стороны на входе и на выходе по отдельности, перестановки сторон, обмен вход↔выход
(обращение времени в смысле Mrini–Hardy). Для Лугано и для каждого элемента группы g
проверить:
- лежит ли ½(Лугано + g·Лугано) в ISO₃;
- причинно ли разделима смесь (точный сертификат, как в T3.0);
- для каких g оба условия выполнены одновременно.

Затем то же для усреднения по подгруппам (смесь по всей орбите). Цель — понять, является
ли инверсия «всё на всё» единственным работающим зеркалом, и что общего у работающих.

## T3.1.e — число сторон

Для N = 4: взять известное N-стороннее обобщение Лугано из литературы (с цитатой),
проверить симметризацию инверсией. Определение ISO_N как пересечение классов «только

## Предрегистрация

Свои предсказания по a–e с уверенностью. Прогнозы архитектора отдельными строками:
- a: понятие «без глобального прошлого» в литературе близко к ISO₃, но симметризация
  Лугано зеркалом с нарушением неравенства явно не выписана (уверенность низкая-средняя —
  риск новизны реальный);
- b: BW16 даёт 1 на Лугано и 0 на зеркале (уверенность средняя);
- c: работает не только полная инверсия (уверенность средняя-низкая);
- e: для N = 4 симметризация тоже работает (уверенность средняя).
